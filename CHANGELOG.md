FileCensus changelog

2026-11-24, v2026.11.24. Created FileCensus, an Android app with a file inventory, file details, notes on AI made files, a timeline, and tags. It then gained a duplicate finder and built in visualizers, including a Circuit mode. A board view now draws the whole file catalog, with a look for each file, and the audio Circuit mode was removed. Deleting is now safer, with a review step, a native confirm, a restorable trash, and a separate erase step.
